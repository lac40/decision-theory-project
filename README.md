# Balancing work, study and gym - an MDP

*Decision Theory, Fontys ICT 2026 Autumn Semester - László Balázs Kornis*

An MDP of my working days as a student and freelance developer: every day I choose between client work, study, gym and rest. New tasks keep arriving, work or study can fail, and nights can be bad. Weekly deadlines and an exam at the end of a 20-day period create the trade-offs.

**Everything is in [`DETH_MDP_work_study_gym.ipynb`](DETH_MDP_work_study_gym.ipynb):**

- the design: states, actions, transitions, rewards, parameters, hypotheses and design changes
- the environment code, which follows the course's optional MDP coding standard
- the Sprint 1 test: a 2-state MDP solved by hand and reproduced in code
- random-policy and rule-based baselines

Requirements: Python 3, `numpy`, `matplotlib`. Run the notebook top to bottom.
